## Reporting a Vulnerability

The MobileVM team takes the security of virtual hardware emulation and host isolation seriously.

If you discover a security vulnerability (such as a guest-to-host sandbox escape, path traversal flaw, or native buffer overflow):

1. **DO NOT** create a public GitHub issue.
2. Please submit a private security advisory on GitHub or email the maintainers directly.
3. Include detailed steps to reproduce the issue, proof-of-concept configuration, and the affected version/device ABI.

We will review, acknowledge, and resolve verified security vulnerabilities in a timely manner before public disclosure.
